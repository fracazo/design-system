# Copy

Load when: any user-facing string, accessible name, error, empty state,
label, or commit message.

Mechanics live in the writing skill (`../../writing/SKILL.md`). Voice,
terminology and examples live in the product's CLAUDE.md. This file does
not set a voice.

- Sentence case for headings, buttons, labels and navigation.
- Verb-first labels that name the action. Where the consequence matters,
  name the object too. Loading states keep the label stable.
- Errors say what to do next, sit next to the failure, and do not blame.
- Claims name only what ships.
- Plain words over clever ones. No machine-written patterns (DESIGN.md,
  Language).
- No em dashes.
- Placeholders are examples, not labels.
- Empty states say what the place is and the next action.

A review of copy is the interface skill, which loads writing.
